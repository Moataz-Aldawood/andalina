Dynamic Source Code Injection

This page demonstrates using <an-code src="..."> to load, escape, and render raw code files directly into your HTML pages without manual copy-pasting.

1. Configuration File (snippets/sample-config.json)

<an-code>

The code block below is dynamically loaded from an external JSON file using <an-code src="./snippets/sample-config.json"></an-code>: 

{
  "name": "andalina-ui-portal",
  "version": "1.1.0",
  "templateEngine": "Andalina",
  "features": [
    "Zero dependency client-side parsing",
    "Declarative components and slots",
    "Dynamic CSS and HTML snippet includes",
    "Grid repeat and master layout support"
  ],
  "settings": {
    "debug": true,
    "cacheTemplates": true,
    "defaultTheme": "dark-glass"
  }
}

2. HTML Component Usage (snippets/component-demo.html)

<an-code>

The code block below demonstrates how Andalina automatically escapes HTML tags when injecting external markup snippets: 

<!-- an-comment: Using an-component with default vs overridden slots -->

<!-- an-comment: 1. Component with Default Values -->
<an-component template="custom-card" src="components/ui-controls.html"></an-component>

<!-- an-comment: 2. Component Overriding Specific Slots -->
<an-component template="custom-card" src="components/ui-controls.html">
   <span slot="title">Enterprise Analytics Dashboard</span>
   <span slot="badge">v2.4 Live</span>
   <span slot="body">
      Real-time data telemetry powered by zero-dependency HTML composition.
   </span>
   <span slot="action">
      <button class="btn btn-primary">Launch Dashboard</button>
   </span>
</an-component>
