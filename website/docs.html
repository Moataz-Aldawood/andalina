Documentation

Learn how to build zero-dependency component architectures using Andalina. Everything runs perfectly in the browser without any build steps.

1. Installation

Simply drop the script tag into the <head> of your HTML document. Ensure you use the defer attribute so it parses after the DOM is ready.

<script src="andalina.js" defer></script>

2. Configuration File

Create an andalina.config.json file in your root directory to configure the engine globally.

{
    "showSource": "disabled",
    "debug": "enabled",
    "preventFOUC": "enabled",
    "propStart": "{{",
    "propEnd": "}}",
    "prefix": "an"
}

Note: propStart and propEnd are mandatory to prevent conflicts with frameworks like Vue or Angular.

3. Master Layouts

Create a master layout (e.g., master.html) and use <an-place> tags to define where content should go.

<!-- master.html -->
<main>
    <an-place name="content"></an-place>
</main>

Then, in your page, use <an-page-template> and <an-inject> to fill that layout:

<!-- index.html -->
<an-page-template src="master.html">
    <an-inject name="content">
        <h1>Hello World!</h1>
    </an-inject>
</an-page-template>

4. Components & Props

You can define variables inside a component using <an-attribute>, and pass them down just like React or Vue!

<!-- button.html -->
<an-attribute name="label" mandatory="true" />
<an-attribute name="theme" default-value="primary" />

<button class="btn btn-{{theme}}">{{label}}</button>

Usage:

<an-component src="button.html" label="Submit" theme="outline"></an-component>
