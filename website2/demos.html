Andalina Advanced Demos

Dynamic Forms

Create complex, reusable forms by combining components and layouts together in Andalina.

Example:

1. The Input Component (input.html)

<an-attribute name="type" default-value="text" />
<an-attribute name="placeholder" />
<div class="field">
    <div class="control">
        <input class="input" type="{{type}}" placeholder="{{placeholder}}">
    </div>
</div>

2. The Form (index.html)

<form>
    <an-component src="input.html" type="email" placeholder="Enter email"></an-component>
    <an-component src="input.html" type="password" placeholder="Password"></an-component>
    <button class="button is-primary">Login</button>
</form>

Rendered HTML:

<form> <div class="field"> <div class="control"> <input class="input" type="email" placeholder="Enter email"> </div> </div> <div class="field"> <div class="control"> <input class="input" type="password" placeholder="Password"> </div> </div> <button class="button is-primary">Login</button> </form>

Deeply Nested Layouts

Andalina natively resolves complex nested layouts without any issues.

Example:

1. Super Master (super-master.html)

<body>
    <nav>Global Nav</nav>
    <an-place name="wrapper"></an-place>
</body>

2. Master (master.html)

<an-layout-template src="super-master.html">
    <an-inject name="wrapper">
        <main>
            <an-place name="content"></an-place>
        </main>
    </an-inject>
</an-layout-template>

3. Page (index.html)

<an-page-template src="master.html">
    <an-inject name="content">
        <p>This content is 3 levels deep!</p>
    </an-inject>
</an-page-template>

Rendered HTML:

<body> <nav>Global Nav</nav> <main> <p>This content is 3 levels deep!</p> </main> </body>

Complex List Rendering

Use components inside of loops to render clean UI dynamically.

Example:

1. Component (card.html)

<an-attribute name="title" />
<div class="box">
    <h4>{{title}}</h4>
</div>

2. Loop (index.html)

<div class="grid">
    <an-repeat times="2" index-as="index">
        <an-component src="card.html" title="Post #{{index}}"></an-component>
    </an-repeat>
</div>

Rendered HTML:

<div class="grid"> <div class="box"><h4>Post #0</h4></div> <div class="box"><h4>Post #1</h4></div> </div>
